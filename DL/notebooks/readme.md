# Структура папки Notebooks:
1) Для каждого эксперимента выделена папка со своим семантическим именем эксперимента
2) Описание эксперимента в формате имя_эксперимента.md
3) Ноутбук с экспериментом (вынесено по-максимуму в ООП, поэтому размер ноутбуков минимизирован). В каждом ноутбуке представлено обучение модели + вывод графиков.
4) Есть подпапка с именем эксперимента, там лежат логи обучения + графики (loss, acuracy, GradCAM и используемые конфиги).

## Хронология и результаты экспериментов

### Эксперимент 1: Базовая емкость и Background Loss
* **Ноутбуки:** `lenet_4kb_vs_2kb_bg_loss_without_augmentations`, `lenet_4kb_vs_2kb_bg_loss_with_augmentations`.
* **Суть:** Сравнение архитектур `LeNet 4KB` (2 слоя свертки) и `LeNet 2KB` (1 слой свертки + агрессивный пулинг). Внедрение пространственного штрафа за активацию на фоне (`Background Loss`).
* **Результаты:** 
  * Без аугментаций обе модели легко достигают >99% точности.
  * При добавлении `RandomPerspective` базовая модель начинает опираться на ложные корреляции (черные углы).
  * `Background Loss` ($\mathcal{L}_{BG} = \alpha \sum (\text{ReLU} \circ \text{Mask})$) очищает карты признаков (Grad-CAM показывает строгий фокус на штрихах)

### Промежуточный эксперимент:
* Идея:разбить нейронку на RotateNet + LeNet. Для старта использовал большой RotateNet~212 KB (см эксперимент `cascade_rotatenet_flatten_220kb`). Далее будет расписано развитие этой идеи. 
### Эксперимент 2: Вращательная эквивариантность (CascadeNet)
* **Ноутбук:** `cascade_rotatenet_cirriculum_learning_with_arcface_32kb`.
* **Суть:** При вращении на $\pm 150^\circ$ декартовы свертки теряют способность извлекать стабильные признаки. Разработана каскадная модель, включающая `RotateNet` для оценки угла и модуль Spatial Transformer Network (STN) для выравнивания.
* **Идеи:**
  * **Spatial Softmax:** Сжатие карт признаков `RotateNet` в 32 точные координаты (Keypoints) без обучаемых параметров, вместо тяжелого `Flatten`.
  * **Iterative STN:** Двойной проход оценки угла с тригонометрическим сложением для избежания размытия.
  * **Polar Feature Fusion:** Перевод декартовых координат $(X, Y)$ в инвариантный радиус $r$ и угол $\phi$. Слияние этих 32 признаков с признаками LeNet.
  * **Curriculum Learning:** Динамическое увеличение угла аугментации от $30^\circ$ до $150^\circ$ в процессе обучения с одновременным затуханием (decay) Background Loss.
* **Результаты:** Точность на тесте с поворотами $\pm 150^\circ$ выросла с базовых $\sim 40\%$ до **95.65%**. Ошибки остались преимущественно на неразрешимых классах (визуальная симметрия '6'/'9', '0'/'о'). Итоговый вес ~32 KB

### Прочие эксперименты: Альтернативные гипотезы латентного пространства
* **Ноутбук:** `advanced_hypotheses_testing`.
* **Суть:** Попытки улучшить разделимость классов в условиях жесткого сжатия (на датасете с перспективой) путем внедрения априорных знаний и метрического обучения.
* **Проверенные гипотезы:**
  1. **Pixel Count (Инженерия признаков):** Добавление доли активных пикселей напрямую в полносвязный слой. Дало дешевый и эффективный прирост точности за счет решения проблемы падения разрешения после `MaxPool`.
  2. **ArcFace (Metric Learning):** Замена классического Linear слоя на вычисление углового отступа ($\cos(\theta + m)$). Показал высокую способность к кластеризации, однако выявил критическую чувствительность к точности `float32` (исправлено через жесткий `.clamp()`). Требует предварительного прогрева (Warmup) базовым лоссом.
  3. **Latent GAN:** Обучение дискриминатора отличать векторы `Flatten` от нормального распределения $\mathcal{N}(0, 1)$. Привело к нестабильности на малых сетях (исправлено через переход от `Sigmoid` к `BCEWithLogitsLoss`).
